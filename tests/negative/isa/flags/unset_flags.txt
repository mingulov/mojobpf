# Unset-flags-shape index for F-ISA/flags/load-opts.
#
# The six BPF_PROG_LOAD prog_flags bits are never set on any
# product load path: every load goes through `bpftool prog
# load` (no flags option exists), and our staged commands,
# CLI, and harness pass none. The UAPI bits and the unset
# surface live in tests/unit/test_prog_flags.py. Kernel-side
# semantics of set flags are out of scope (we never set
# them). This file indexes the vectors so reviewers can
# audit coverage without reading the test body.
#
# Format: <vector> | <asserting test> | <expected outcome>
#
STRICT_ALIGNMENT bit 0 | test_prog_flags_uapi_bits | effective-by-default, relied upon implicitly, never set explicitly
ANY_ALIGNMENT bit 1 | test_prog_flags_uapi_bits | unset by construction; strict-arch relaxation out of profile
TEST_RND_HI32 bit 2 | test_prog_flags_uapi_bits | unset by construction; verifier-internal test flag, out of profile
TEST_STATE_FREQ bit 3 | test_prog_flags_uapi_bits | unset by construction; verifier-internal test flag, out of profile
SLEEPABLE bit 4 | test_prog_flags_uapi_bits | unset by construction; sleepable hooks out of the XDP profile
TEST_REG_INVARIANTS bit 7 | test_prog_flags_uapi_bits | unset by construction; verifier-internal test flag, out of profile
verify.py staged load | test_verify_staged_load_carries_no_flags | exactly `$LOAD_RUN prog load "$OBJ" "$PIN"`, no flags
Q-harness load argv | test_harness_load_argv_carries_no_flags | 5-element [bpftool, prog, load, object, pin], no flags
CLI + harness options | test_cli_and_harness_expose_no_prog_flag_option | no sleepable/align/prog-flag/test-* option
product tree setters | test_no_prog_flags_setter_in_tree | no set_flags/prog_flags/bpf_prog_load/owned-macro outside this index + the suite
