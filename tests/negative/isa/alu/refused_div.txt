# Refused-division corpus index for F-ISA/alu/arith64.
#
# The vectors live in compiler/tests/test_isa_alu64.py (RED-first,
# frozen before the checked-division rule existed). This file indexes
# them so reviewers can audit coverage without reading the test body.
# Every vector below is refused at the parsed layer (check-target
# exits 4 with MBPF319); nothing here reaches llc, the verifier, or
# a guest.
#
# Format: <vector> | <asserting test> | <expected outcome>
# The only admitted div/rem shape is udiv/urem i64 with a nonzero
# constant divisor (test_alu64_admit_div_k_nonzero,
# test_alu64_admit_mod_k_nonzero, entry site;
# test_alu64_admit_div_k_nonzero_subprog, subprogram site).

udiv i64 K=0 | test_alu64_refused_div_shapes | exit 4, MBPF319 unchecked division
urem i64 K=0 | test_alu64_refused_div_shapes | exit 4, MBPF319 unchecked division
udiv i64 X | test_alu64_refused_div_shapes | exit 4, MBPF319 unchecked division
urem i64 X | test_alu64_refused_div_shapes | exit 4, MBPF319 unchecked division
sdiv i64 K-nonzero | test_alu64_refused_div_shapes | exit 4, MBPF319 unchecked division
srem i64 K-nonzero | test_alu64_refused_div_shapes | exit 4, MBPF319 unchecked division
udiv i32 K-nonzero | test_alu64_refused_div_shapes | exit 4, MBPF319 64-bit slice
urem i32 K-nonzero | test_alu64_refused_div_shapes | exit 4, MBPF319 64-bit slice
sdiv i32 K-nonzero | test_alu64_refused_div_shapes | exit 4, MBPF319 64-bit slice
udiv i32 X | test_alu64_refused_div_shapes | exit 4, MBPF319 64-bit slice
udiv i64 X in subprogram | test_alu64_refused_div_x_subprog | exit 4, MBPF319 unchecked division
