# Oracle construct probes (llc 22.1.8; the leaf asserts the parsed
# layer agrees with the oracle):
# - LDX at B/H/W/DW (test_mem_oracle_emission ld_b_off/ld_h/
#   ld_w/ld_dw)
# - sign extension via LDX + LSH-K + ARSH-K at B/H/W
#   (test_mem_oracle_emission ld_sx_b/ld_sx_h/ld_sx_w)
# - STX at B/H/W/DW (test_mem_oracle_emission st_b/st_h/
#   st_w/st_dw)
# - immediate stores expand to MOV-K + STX (st_imm_w/st_imm_dw)
# - ld_imm64 selects the 0x18 two-slot pair (ld_imm64)
# - i32 allocas spill via r10 STXW with a forwarded use
#   (alloca_use)
# - no MEMSX word on v3 (test_mem_oracle_no_memsx; opcodes
#   derived in test_mem_memsx_opcode_derivation; injected
#   words caught in
#   test_mem_oracle_no_memsx_catches_injected_words)
# - no ST word on v3 (test_mem_oracle_no_st)
#
# Shape boundaries (packet): map/scratch cell semantics belong
# to their suites (the root+offset guarantee rule is cited,
# not re-proved), PSEUDO imm64 variants to the pseudo-imm64
# leaf, atomics to the atomic leaf, call semantics to F-CALLS,
# JMP forms to the cond leaf. This leaf pins load/store words,
# not those semantics.
